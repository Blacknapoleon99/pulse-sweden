KNOW YOUR SOURCE

Awareness, with context.

Pulse is an independent concept demo using the Swedish Police’s public events API. It is not affiliated with Polisen.

The feed contains up to 500 recent reports and covers a selection of police activity. Reports may appear hours after an event, and initial information can change.

Map markers show municipality or county centres supplied by the API, never an exact incident address. Marker numbers group reports sharing the same coordinates. Colours describe categories, not danger levels.

We check for updates every 65 seconds. Times are shown in Europe/Stockholm. Report text stays in its original Swedish.

Publication boundary: Pulse does not infer or publish where suspects or convicted people live. Any future manual area must be coarse, backed by an official source, reviewed, and have an expiry date. Court material belongs in a legal-updates layer and is never joined to homes or inferred “criminal” areas.

Polisen event API ↗Skatteverket statistics API ↗DIGG open data directive ↗Domstolsverket rättspraxis API ↗

The Skatteverket page documents aggregated, machine-readable statistics available through Sveriges dataportal. DIGG describes the Swedish and EU framework for making public data open and reusable. Domstolsverkets linked dataset is published court practice from higher instances, not a general tingsrätt feed. These are context links for future civic-data connectors; the live map currently uses Polisen only.
