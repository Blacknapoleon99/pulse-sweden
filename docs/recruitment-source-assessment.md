## Implementation rule

The current admin map workflow accepts reviewed, source-linked notices with a validity end date. For any recruitment-related notice, an editor should confirm that the source **explicitly** describes the place and claim, choose a coarse enough scope, record its publication date, and set an expiry. The app displays these as *TryggPuls-granskad kartpost*; the map does not infer new boundaries from police report points. Saved family places and reviewed service points carry no safety guarantee.

**Decision:** use the existing official area layer and manually reviewed source notices. Do not add a recruitment hotspot dataset, keyword classifier, or predictive score unless a later source provides suitable geography, dates, rights, and a validated update process.
